# Discord VC Joiner Bot

Advanced Discord bot that can join voice channels and stay 24/7 with auto-reconnect.

## Features
- ✅ Join any user's voice channel (`!jvc @user`)
- ✅ Leave voice channel (`!lvc`)
- ✅ 24/7 voice channel presence
- ✅ Auto-reconnect on disconnect
- ✅ Self-deafened mode
- ✅ Streaming status
- ✅ Advanced error handling
- ✅ Connection status monitoring
- ✅ Silent audio player for 24/7 operation

## Installation

1. Install Node.js v16 or higher
2. Clone or download this repository
3. Run `npm install` to install dependencies
4. Create a `.env` file with your bot token
5. Run `npm start` to start the bot

## Commands
- `!jvc` - Join your voice channel
- `!jvc @user` - Join mentioned user's voice channel
- `!lvc` - Leave current voice channel
- `!status` - Check connection status
- `!help` - Show all commands
- `!ping` - Check bot latency
